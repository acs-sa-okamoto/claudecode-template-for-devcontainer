## 使い方（AI 向け）

1. まずこのファイルだけを読む。
2. 下の「知りたいこと → 読むファイル」で、**必要なファイルだけ**を読む（全部は読まない）。
3. 深さが「浅い」「未探索」の区画と、「深い（範囲）」の範囲の外は、**書かれていないことが「存在しない」ことを意味しない**。コードを直接調べる。
4. 🔵 は根拠を機械検証したもの、🟡 は妥当な推測、🔴 は推測。**コードと食い違ったらコードが正しい**。
5. 検証リビジョンが今のコミットと違うときは、先に鮮度を確かめる（`check-atlas-freshness.sh`）。
