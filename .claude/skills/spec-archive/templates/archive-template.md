# 片付けの記録（ARCHIVE）

<!--
docs/spec/ARCHIVE.md。完了した機能の作業用の文書を、Git の履歴へ移した記録。消したのではなく、取り出せる。
spec-archive が行を足す。1 行目から順に、新しいものを下へ足す。
-->

完了した機能の作業用の文書（note・理解ブリーフ・設計・TASK・実装のメモ・レビュー など）は、現役の仕様（[current/](current/README.md)）へ要件をまとめたうえで、Git の履歴へ移した。

**取り出し方**（取り出したものはコミットしない）:

```bash
git ls-tree -r --name-only <取り出すコミット> -- docs/tasks/<名前>   # 何があったかの一覧
git show <取り出すコミット>:<パス>                                   # 1 本を読む
git worktree add ../old-docs <取り出すコミット>                      # まとめて読む（別のフォルダに当時の状態を開く。終わったら git worktree remove ../old-docs）
```
