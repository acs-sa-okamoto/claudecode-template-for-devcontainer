# パターン2: ビジネス（テンプレート型）

> slide-maker **step3（デザイン刷新）** が、slide-plan の「デザイン」に **ビジネス** と書かれたときに使う（書かれていなければ従来どおり `design-directions.md`＝標準デザイン）。内容（outline.md のテキスト・枚数・順序）は一切変えない。
> 出自: ユーザー提供の `デザイン見本2.pptx`（社内テンプレートで作った提案書）の**本文ページ**をトークン化したもの（2026-11 確定）。表紙は対象外。
> **品質の土台は `visual-rubric.md`**。ただし下の「ルーブリックとの関係」にある意匠は、このパターンでは欠陥・定型として扱わない。

## このパターンの前提（標準デザインとの違い）

| | 標準デザイン | ビジネス（このパターン） |
|---|---|---|
| 作るもの | 表紙から締めまでの全ページ | **本文ページだけ**（表紙・締め・中扉は作らない。ユーザーが自分の表紙と締めの間に貼る） |
| 土台 | 白紙から pptxgenjs で組む | **会社のテンプレート（.pptx）を開き**、そのレイアウトに本文ページを足す（python-pptx） |
| ロゴ・罫線・コピーライト・ページ番号 | 使わない | **テンプレートのマスターが自動で描く**（スライドには描かない） |
| 雰囲気 | 3色・角丸ゼロ・余白広め | 紺と青の濃淡・情報量多め・カードと帯で区切る、日本の提案書の定型 |

- **テンプレートはスキルに同梱しない**（ロゴ入りの社外秘ファイルのため）。置き場所は slide-plan の「テンプレート」欄で指定する。既定は作業フォルダから上にたどって見つかる `proposals/_library/templates/proposal-template.pptx`。
- テンプレートは **スライド 0 枚の基盤テンプレート**であること。元の提案書（顧客名・作成者名・サムネイル入り）からは、同梱の `assets/make_base_template.py` で作る（マスター・レイアウト・テーマだけを残し、スライド・変更履歴・サムネイル・文書プロパティ・セクション一覧を消す）。
- 使うレイアウトは本文用の **`2_タイトルとコンテンツ`**（タイトルのプレースホルダだけを使い、本文のプレースホルダは消して図形で組む）。

## グリッド

- スライド 13.333 × 7.5in。**本文の左端 0.46in・幅 12.42in（右端 12.88）**。罫線・サブタイトル帯と左右の端をそろえる。
- 縦の帯: タイトル y 0.38 ／ 罫線 y 0.90 ／ **サブタイトル帯 y 1.02〜1.49** ／ リード文 y 1.62〜 ／ 本文 〜y 6.1 ／ まとめ帯 y 6.1〜6.65 ／ 注記 y 6.7〜6.85。

## パレット（役割 → hex）

| 役割 | hex | 用途 |
|---|---|---|
| 紺（navy） | `17375E` | カード上の見出し帯・強調文字（リード文の強調・カード内の見出し）・STEP 1・**結論の濃色帯**（白文字） |
| 青（mid） | `4F81BD` | 矢羽根（STEP 2 以降）・番号／アイコンの丸・表の見出し行 |
| 帯の文字（tx2） | `1F497D` | サブタイトル帯の文字 |
| 帯の地（tint） | `CCDDF2` | サブタイトル帯の地 |
| まとめの地（msg） | `DEF2FF` | まとめ帯・補足の面（「本件との関連」など） |
| ごく淡い面 | `F2F6FB` | 表の縞・矢印でつないだ列の地 |
| 枠・区切り | `D9D9D9` | カードの枠（1pt）・行の区切り線 |
| 本文 | `000000` | 本文・表の中身 |
| 注記 | `7F7F7F` | 出典・注記・補足の小さな字 |
| 注意印 | `C0504D` | ★（必ず確認したい項目）などの印だけ。1ページ数か所まで |
| 白 | `FFFFFF` | 背景・カードの面・濃色の上の文字 |

- 色はこの表だけ。鮮やかな色を足さない。強調は「紺の太字」か「まとめ帯」で作る。

## タイポグラフィ（すべてメイリオ。欧文も和文もメイリオ）

| 役割 | サイズ | 太さ | 色 |
|---|---|---|---|
| ページタイトル（「N．章名」） | 28 | 太 | 000000 |
| サブタイトル帯（「N－M．小見出し」または問い） | 24 | 太 | 1F497D |
| リード文 | 16（強調部・紺）＋14（続き・黒） | 太／標準 | 17375E／000000 |
| 見出し帯・カードの見出し | 14〜15 | 太 | 白（帯）／17375E（カード内） |
| 矢羽根の文字（STEP n） | 16 | 太 | 白 |
| 本文・箇条書き | 12〜14（情報量が多いページは 11.5 まで） | 標準 | 000000 |
| 表 | 13（列が多いときは 11.5） | 見出し行は太 | 白（見出し）／000000 |
| まとめ帯 | 14〜16 | 太 | 17375E |
| 注記・出典 | 10.5 | 標準 | 7F7F7F |

- タイトルは **「1．」「2．」…＋全角ピリオド**、サブタイトルは **「3－1．」**（全角ダッシュ）で章番号をそろえる。参考資料の章はタイトルを「参考資料」に統一し、中身はサブタイトル帯に書く。
- 箇条書きの行頭は「・」、ブロックの見出しは「◆」、注意は「★」（`C0504D`）、注記は「※」。

## 部品（`assets/pptx_template_kit.py` の関数名つき）

| 部品 | 形 | 関数 |
|---|---|---|
| サブタイトル帯 | 全幅の矩形（y 1.02・高さ 0.47）、地 `CCDDF2`、24pt 太字 `1F497D`、左の内余白 0.2in | `subtitle_bar` |
| リード文 | 帯の直下 1〜2行。強調部 16pt 紺太字＋続き 14pt | `lead` |
| カード | 角丸ごく小（調整値 0.04）・白・枠 `D9D9D9` 1pt・**薄い影**（下へ 0.02in、ぼかし 0.05in、黒 20%） | `card` |
| 見出し帯 | カードや列の上辺に載せる矩形（高さ 0.42）、紺地・白 14pt 太字・左寄せ | `header_bar` |
| 細枠の囲み | 角丸（0.12）白・紺 1.5pt の枠・14pt 紺太字・中央 | `outline_box` |
| STEP の矢羽根 | 1つ目は五角形（紺）、2つ目以降は山形（青）、高さ 0.5、16pt 白太字 | `step_flow` |
| 番号の丸 | 円（直径 0.38〜0.6）青地・白抜き数字。アイコンの代わりにも使う | `num_circle` |
| 区切り線 | 高さ 0.01 の `D9D9D9` | `separator` |
| まとめ帯 | 全幅の矩形（高さ 0.45〜0.6）、地 `DEF2FF`、紺太字。**1ページに1本まで** | `message_band` |
| 結論の濃色帯 | 表の直下などに置く紺地・白太字の帯（2行目に白の小さな補足） | `box(fill=NAVY, color=WHITE)` |
| 表 | 見出し行は青地・白太字、本文は白と淡青の縞、行の高さ 0.39〜0.42 | `table` |
| 箇条書き | 「・」を文字で付け、段落の後ろに 3〜8pt の間隔 | `bullets` |
| 注記 | 10.5pt 灰 | `footnote` |

- 角丸はカード（ごく小）と細枠の囲みだけ。帯・表・矢羽根は角を立てる。
- アイコンは画像を描かない（番号の丸か「◆」で代える）。図やスクリーンショットが必要な箇所は、灰色の枠に「（図：○○）」と書いた置き場所にしておく。

## ページの型（見本で使われていたもの）

内容に合わせて選ぶ。同じ型を3枚以上続けない。

1. **進め方・アジェンダ**: 番号の丸＋項目（18pt 紺太字）＋右寄せの時間、行ごとに区切り線。
2. **2列の対比**（現状／課題、私どもの理解 など）: 見出し帯つきのカードを2つ並べ、下にまとめ帯。
3. **STEP の流れ**: 矢羽根を横に並べ、その下に同じ幅のカード（番号の丸・見出し・説明）、最下部にまとめ帯。カードの下に細枠の囲みで「決めること」を添えてもよい。
4. **3〜5枚のカード**（テーマ・事業・観点）: 等幅のカード、各カードに番号の丸か見出し帯。
5. **確認項目の表**（No.／項目／内容）: ★で必須を示し、表の下に結論の濃色帯か注記。
6. **比較の表**（選択肢 × 観点）: 1列目を太字、表の下に結論の濃色帯。
7. **構成図・業務の流れ**: 見出し帯つきの列を3つ程度、列のあいだに灰色の矢印、列の中に白い小カード。
8. **年表**: 横の線に丸を並べ、下に年ごとのカード。
9. **写真・図＋カード**: 左に図の置き場所、右に見出しつきのカードを縦に3つ。

## ルーブリックとの関係（このパターンでの例外）

`visual-rubric.md` の C層のうち、次はこのパターンの意匠なので**指摘しない**:

- タイトル下の水色の罫線（テンプレートのマスターにある）
- サブタイトル帯・見出し帯・まとめ帯（全幅の帯）
- カードの薄い影（上の値のものだけ。濃い影・ぼかしの大きい影は従来どおり指摘する）
- 全ページ同じタイトル位置・帯の位置（統一感の意匠）

一方、次はこのパターンでも指摘する: 帯の多用（1ページにまとめ帯2本以上）・パレット外の色・本文 10.5pt 未満・本文がまとめ帯や注記と重なる・ロゴや罫線の領域への食い込み（A層の重なりとして扱う）。

## design-mock.html の描き方（step3）

- 各スライドに**テンプレートの外枠を仮に描く**: 右上に灰色の枠「ロゴ」、y 0.90 の水色の罫線（`00B0F0`）、下中央に灰色の「コピーライト」、右下に番号。**実物のロゴ画像は使わない**（HTML に会社のロゴを入れない）。
- 本文は上の部品と色だけで描く（PPTX で表現できない効果は使わない）。
- 表紙・締めはモックにも作らない。冒頭に「本文ページのみ（表紙と締めは手元の資料を使う）」と書いておく。

## PPTX の組み方（step4・step5）

- pptx スキル（pptxgenjs）には委譲しない（pptxgenjs は既存のテンプレートを開けない）。**python-pptx と `assets/pptx_template_kit.py` で組む**:

  ```python
  import sys; sys.path.insert(0, r"C:/Users/<ユーザー>/.claude/skills/slide-maker/assets")
  from pptx_template_kit import *
  deck = Deck(r"<テンプレート>")            # スライド 0 枚の基盤テンプレート
  s = deck.slide("3．進め方のご提案")         # タイトルはレイアウトのプレースホルダへ
  subtitle_bar(s, "つくる前に、業務の流れから")
  lead(s, "いきなり仕組みをつくるのではなく、現状の業務を一緒に確かめてから進めます。")
  shapes, w = step_flow(s, ["STEP 1", "STEP 2", "STEP 3", "STEP 4"], y=2.2)
  ...
  message_band(s, "本日は STEP 1 から始めます。", y=6.1)
  deck.save(r"<作業フォルダ>/<タイトル>_draft.pptx")
  ```

- 実行は `PYTHONUTF8=1 python <スクリプト>`。`pptx-postprocess.js` は不要（キットが全ランにメイリオを和文・欧文とも指定する）。
- 描画の確認は標準と同じく `render-pptx.ps1`。
