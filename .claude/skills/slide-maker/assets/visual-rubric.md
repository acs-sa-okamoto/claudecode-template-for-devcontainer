# ビジュアル・ルーブリック（磨き上げ判定基準）

> slide-maker **step5（ビジュアル磨き上げ）** が `<タイトル>_draft.pptx` → `<タイトル>.pptx` に仕上げる際の判定基準。
> 3層構造: **A=欠陥（必ず直す）／B=原則（原則直す。逸脱するなら理由を言う）／C=定型回避（AIっぽさの排除）**。
> 好み・トーンの層は本ルーブリックの範囲外 — `design-spec.md`（無ければ `style-guide.md`）とユーザーのレビューに委ねる。矛盾したらそちらが優先。
> 案件ごとに基準を変えたい場合は、このファイルを作業フォルダに `visual-rubric.md` としてコピーして編集する（そちらが優先される）。

## A. 欠陥 — 1つでも残っていれば不合格（機械判定できる）

- [ ] **はみ出し**: テキストが図形やスライドの外にはみ出す／切れている
- [ ] **意図しない重なり**: 文字と文字、線が文字を貫通、要素同士の衝突（意図的なレイヤー表現は除く）
- [ ] **余白違反**: スライド端から 0.4 インチ未満に本文要素がある
- [ ] **コントラスト不足**: 薄い地に薄い文字など（目安: 本文 4.5:1、20pt超の大きな文字 3:1）
- [ ] **極小フォント**: 本文 10.5pt 未満
- [ ] **不自然な折り返し**: 句読点や括弧だけが次行に落ちる、1〜2文字だけの行
- [ ] **残骸**: プレースホルダ・ダミーテキスト・生成時のはみ出た図形

## B. 原則 — 磨き上げの中核（画像を見て判定する）

デザイン4原則（近接・整列・反復・対比）のスライド適用。

1. **整列**: 見えないグリッドに揃える。
   - タイトルの位置・本文の左端・カード間隔が**全スライドで一致**している
   - 同種の要素（カード・チップ・図形）の上端／中心が揃っている
2. **階層（対比）**: 1枚の中で視線の順番が明確。
   - サイズ差の目安: タイトル : リード : 本文 ≒ 2 : 1.3 : 1
   - 最も伝えたい1点が最も目立つ（強調は1スライド1箇所）
3. **余白（近接）**: 詰め込まず、関係の強い要素を近く、弱い要素を遠く。
   - 要素間の間隔を 0.3〜0.5 インチで一定に
   - 空白が片側に偏らない（左右・上下の視覚的バランス）
   - 縦方向の使い方: コンテンツをスライドの垂直中心帯に置き、下部だけ間延びさせない
4. **反復（統一感）**: モチーフを全スライドで繰り返す。
   - 角丸の半径・線の太さ・チップ／バッジの形・番号表現が統一されている
   - 同じ役割のテキスト（リード文・キャプション・出典）は同じサイズ・色
5. **色の規律**: パレット外の色を使わない（基準パレットは `design-spec.md`、無ければ `style-guide.md`）。
   - アクセント色は「1スライド1強調」に限定（面積の目安 5〜10%）
   - グレースケール印刷でも階層が読める（色だけに意味を持たせない）
6. **図解優先**: 文字だけのスライドを作らない。
   - 箇条書きが5行を超えたら、カード化・図解化・分割を検討
   - 図解の線・矢印は最小限の太さと本数で（意味のない装飾線を足さない）

## C. 定型回避 — 「AIが作った感」の排除（見つけたら直す）

- [ ] タイトル下のアクセント罫線（AI生成スライドの典型）
- [ ] 全幅の装飾バー・ヘッダー/フッター帯・サイドリボン
- [ ] 意味のないクリーム／ベージュ背景（白または style-guide の背景色を使う）
- [ ] 過剰な影・グラデーション・立体効果
- [ ] 全スライドが同一レイアウトの機械的繰り返し（内容に応じて変化させる。ただし B-4 の統一感は保つ）
- [ ] 意味のないストック写真・クリップアート

## 運用ルール

1. ドラフトを**画像化**し、スライドごとに **A → B → C の順**で指摘を列挙する（画像なしで判定しない）
2. 指摘には必ず「スライド番号・現象・修正方針」を付ける
3. 修正 → 再レンダリング → A層ゼロを確認
4. 修正サイクルは**最大2周**。B/C の軽微な指摘で無限に磨かない（完璧よりも一貫性）
5. 判断に迷う「好み」の問題はユーザーのレビュー・ゲートに委ねる
